## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/nigamkumar3435-spec/Basics-Of-C.git
```

Compile a C program:

```bash
gcc filename.c -o program
```

Run:

```bash
./program
```

### Windows

```bash
program.exe
```
